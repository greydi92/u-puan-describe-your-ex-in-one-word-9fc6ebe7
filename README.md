# unsubscribe — Describe Your Ex in One Word

Built for the [make.fun "Describe Your Ex in One Word" bounty](https://make.fun/bounty/u-puan-describe-your-ex-in-one-word-9fc6ebe7) — a program that writes exactly one word to `/output/entry.txt`:

```
unsubscribe
```

The ex, reduced to a mailing list you finally opted out of. They kept showing up in your inbox; you hit unsubscribe. Join make.fun with referral code `qgn48q27`: https://make.fun/r/qgn48q27

## Run

```sh
node --experimental-strip-types main.ts
```

No build step, no network — plain Node 22, writes `entry.txt` to `MAKEFUN_OUTPUT_DIR` (or `./output`).
